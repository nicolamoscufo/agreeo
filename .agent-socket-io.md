# Agent Prompt: Real-Time Socket.io Implementation for Agreeo

## 🎯 Obiettivo Principale
Implementare un sistema **real-time** completo per Agreeo utilizzando Socket.io:
- Notifiche live per richieste di amicizia (invio, accettazione, rifiuto)
- Notifiche live per inviti movie night (creazione, invito, risposta, aggiornamenti)
- Pagina **Notifications** dedicata con 2 tab (Amici | Movie Nights)
- Inviti **in-app** senza share link pubblico (rimuovere la funzione link)
- Senza aggiungere la pagina alla BottomNavBar (accessibile da icon in AppBar o drawer)

## 📋 Task Backend (Node.js)

### 2. Modifica `server.js`

- [ ] Aggiungi handler `disconnect`
- [ ] Export dell'istanza `io` per usarla in altri moduli

### 3. Modifica `socialController.js`
Aggiungi emissioni Socket.io a questi endpoint:

**POST /friends/request**
- Dopo DB write: `io.to(\`user_${recipientUserId}\`).emit('friend_request_sent', {...})`
- Payload: `{fromUserId, fromUserName, fromAvatar, timestamp}`

**POST /friends/accept**
- Dopo DB write: `io.to(\`user_${requesterUserId}\`).emit('friend_request_accepted', {...})`
- Payload: `{accepterUserId, accepterName, timestamp}`

**POST /friends/reject**
- Dopo DB write: `io.to(\`user_${requesterUserId}\`).emit('friend_request_rejected', {...})`
- Payload: `{rejecterUserId, timestamp}`

**DELETE /friends/:friendId**
- Dopo DB write: `io.to(\`user_${friendId}\`).emit('friend_removed', {...})`
- Payload: `{removedByUserId, removedByName, timestamp}`

**RIMUOVI la funzione share link** se esiste (niente URL pubblici)

### 4. Crea/Modifica `movieController.js`
Aggiungi questi endpoint e emissioni:

**POST /movie-nights/create**
- DB: Crea nodo MovieNight in Neo4j
- Socket: `io.to(\`user_${recipientId}\`).emit('movie_night_invitation', {...})` per ogni invitato
- Payload: `{creatorId, creatorName, movieNightId, title, date, poster, invitees: [{id, name}], timestamp}`

**POST /movie-nights/:id/respond**
- DB: Aggiorna relazione in Neo4j con status (ACCEPTED/REJECTED)
- Socket: `io.to(\`user_${creatorId}\`).emit('movie_night_response', {...})` al creator
- Payload: `{responderId, responderName, movieNightId, response: 'accepted'|'rejected', timestamp}`
- Socket: `io.emit('movie_night_response', {...})` a tutti gli altri partecipanti

**PUT /movie-nights/:id**
- DB: Aggiorna MovieNight
- Socket: `io.emit('movie_night_updated', {...})` a tutti i partecipanti
- Payload: `{movieNightId, updatedFields: {title?, date?, description?}, updatedBy, timestamp}`

**GET /notifications/pending?userId={id}** (NEW)
- DB: Query notifiche pending (richieste amicizia non lette + inviti movie night non letti)
- Response: `{friendRequests: [...], movieNightInvitations: [...]}`

### 5. Aggiorna `package.json`
Verificare che le dipendenze siano presenti:

```json
  "socket.io": "^4.x"
}
```

## 🔄 Socket.io Event Map

### Friend Events
```
FROM backend TO frontend (quando ricevi evento Socket.io):
- 'friend_request_sent': {fromUserId, fromUserName, fromAvatar, timestamp}
- 'friend_request_accepted': {accepterUserId, accepterName, timestamp}
- 'friend_request_rejected': {rejecterUserId, timestamp}
- 'friend_removed': {removedByUserId, removedByName, timestamp}
```

### Movie Night Events
```
FROM backend TO frontend:
- 'movie_night_invitation': {creatorId, creatorName, movieNightId, title, posterUrl, date, timestamp}
- 'movie_night_response': {responderId, responderName, movieNightId, response, timestamp}
- 'movie_night_updated': {movieNightId, changes, updatedBy, timestamp}
```

## 🛠️ Notes Tecniche
- Socket.io auto-fallback a polling se WebSocket non disponibile
- Usa `socket.join(\`user_${id}\`)` per room privata per utente
- Emetti a room singola con `io.to(room).emit()`
- Considera namespace `/notifications` per organizzazione
- Implementa heartbeat/ping-pong per rilevare disconnessioni
- Aggiungi timeout reconnect (default 5s)
